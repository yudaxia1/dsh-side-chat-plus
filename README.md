# dsh-side-chat

DeepSeek Harness Web 的**侧边聊天**插件：在主会话右侧打开独立的对话空间，像 Codex 一样
“对着一条消息、一段选中文字开一个小窗讨论”，不污染主会话。

## 功能

- **独立侧聊面板**：右侧可拖宽的面板（窄屏自动变全屏抽屉），与主聊天同时显示、同时工作。
- **三种创建方式**：
  - 「侧聊」头部按钮 → 面板内「新建空白侧聊」；
  - 每条**助手消息**上的「在侧聊中询问」按钮（先选中文字则引用选中内容）；
  - 面板内「引用最近的主聊天消息」弹层（列出最近 10 条用户/助手消息）。
- **独立消息流**：侧聊发送走独立的模型流，与主 Agent 循环互不干扰；流式期间可随时「停止」。
- **接近 Codex 的面板体验**：面板可拖拽宽度、窄屏全屏、自动跟随流式输出、生成中/停止中状态、首条提问自动命名、消息一键复制，以及关闭后的焦点恢复。
- **最小必要快照**：新建侧聊只携带引用的那一条消息 + 前面那条用户提问（截断 4000 字符），
  不复制整段主会话，也不在每轮自动同步主会话。
- **回传主聊天**：只有点击「插入主聊天输入框」或「总结到主聊天」（模型生成摘要）后，
  内容才进入主输入框——**默认不自动发送**，由你在主输入框确认。
- **多侧聊管理**：新建 / 切换 / 重命名 / 删除；同一主会话可保存多个侧聊，同一时间只显示一个。
- **来源定位**：点击锚点「定位」按钮，主聊天滚动到原始消息。
- **持久化**：侧聊记录存于 `~/.dsh/storages/side_chat.json`，刷新网页、重开浏览器、
  重启 DSH 后列表/消息/标题/引用关系仍在。
- **隔离**：侧聊以 `parentSessionId` 归属主会话，跨会话读写一律拒绝；删除侧聊不影响
  主会话与其他侧聊。
- **安全**：侧聊是无工具的分析/讨论空间（不执行命令、不改文件、不提交代码）；
  需要执行修改时，把结论带回主输入框由你确认执行。消息渲染不做 HTML 解析。

## 要求

- DeepSeek Harness（Web GUI），含 `storage-domain`、`session-query`、`llm` 等 host 服务
  （标准 web profile 已具备）。
- 以**动态 Cordis 插件**方式加载（`cordis_define` + `cordis_run`），每个会话加载一次。

## 使用

1. 打开任意会话，点头部「侧聊」按钮 → 右侧出现面板。
2. 「＋」新建空白侧聊；或点击任意助手消息上的「在侧聊中询问」直接开一个有引用的侧聊。
3. 在面板输入框提问（Enter 发送，Shift+Enter 换行），生成期间可「停止」。
4. 讨论完：
   - 「插入主聊天输入框」：把最后一条问答放入主输入框（追加到已有草稿之后）；
   - 「总结到主聊天」：让模型总结侧聊，摘要放入主输入框。
   - 都不自动发送；确认后自行发送。
5. 点锚点上的「定位」可跳回主聊天里的原始消息；「重命名」「🗑 删除」管理侧聊。

## 键盘与可访问性

- `Enter` 发送 / `Shift+Enter` 换行；`Esc` 关闭面板并回到主界面焦点。
- 面板 `role="complementary"`，消息列表 `aria-live="polite"`，按钮均带 `aria-label`。

## 已知限制（MVP）

- 动态宿主沙箱禁 `require`/`AbortController`，持久化用透传 schema 打开 storage domain、
  取消走迭代器 `return()` 级联——见 [docs/RESEARCH.md](./docs/RESEARCH.md)。
- 流式期间客户端 ~400ms 轮询（无 Host→Client 推送通道）。
- 工具结果/文件引用暂未提供逐条锚点入口（见 RESEARCH §3.6）。
